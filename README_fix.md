# 하천수위변동 모델링

## 1. 프로젝트 개요

### 1.1 목적
- 기상·수문 데이터를 활용한 하천수위 상승량 예측

### 1.2 모델링 방법론
- EDA와 기본모델링을 통해 확인한 정보를 기반으로 관측소를 2개 그룹으로 분리, 특성별 모델링

### 1.3 최종 모델
- **특이그룹(Tidal 그룹)**
  - 학습 방식: 단일 홀드아웃
  - 적용 모델: CatBoost, ExtraTrees 앙상블
- **일반그룹(Normal 그룹)**
  - 학습 방식: 5-Fold 교차검증
  - 적용 모델: CatBoost 앙상블

### 1.4 차별점
- 도메인전문가(팀원 전체가 물관리분야 재직경력 10년 이상)로 구성된 팀
- 목적이 없는 모델튜닝을 지양하고 도메인 지식을 기반으로 가설설정과 검증을 반복
- 단순히 이번 데이터에 RMSE가 낮은 모델이 아니라 현장 적응력이 높은 모델 추구

## 5. 모델 설명

### 5-1. 모델 개요
본 모델은 기상·수문·유역환경 데이터를 활용하여 하천수위 상승량을 예측하는 머신러닝 기반 회귀 모델입니다.
 - 탐색적 데이터 분석(EDA)과 모델링 과정에서 일부 관측소의 수위 변동에서 약 12시간의 주기성 발견
 - 관측소별 데이터 개수에서 주기성 추정 데이터 비율이 10% 이상인 9개 관측소를 **Tidal그룹**, 나머지 관측소는 **Normal그룹**으로 분류
 - 각 그룹별 예측력이 높은 모델로 별도 모델링

### 5-2. 모델 특성
 - Tidal그룹은 단일 홀드아웃방식에 CatBoost(45%), ExtraTrees(55%) 앙상블로 예측
 - Normal그룹은 K-Fold 교차검증방식에 CatBoost 모델의 앙상블(산술평균)로 예측
 - 최종적으로는 **두 그룹의 예측값을 결합하여** 전체 Test 데이터를 예측

### 5-3. 모델 사용 방법
본 프로젝트의 모든 Notebook은 Windows 11 환경의 VS Code 및 Jupyter Notebook을 기준으로 작성되었습니다.

## 9. 주요 검토과정

### 9.1 수위차분변수의 이상거동 분석 및 모델 개선
#### 9.1.1 실험배경 및 가설1 수립
 - 수위파생변수(과거 3·6시간 수위변동량)의 피어슨 상관계수가 스피어만 계수보다 비정상적으로 높고, 수위하강 구간에서는 종속변수와 강한 음의 상관관계(r ≈ -0.8) 확인  **(Fig9-1)**
 - 특히 6시간 수위변동량이 -4m 미만인 관측소는 3개(ST0358, ST0292, ST0326)로 한정되며, 과거 6시간 수위변동량과 미래 6시간 최대 수위상승량의 합이 0 부근에 집중  **(Fig9-2)**
 - 가설: 일부 관측소의 일시적 수위 과소계측(과거 수위변동 < 0) 및 정상화 과정(미래 수위변동 > 0)에서 발생한 계측오류로 추정

#### 9.1.2 가설1 검증(RMSE 감소 실패)
 - 모델링 결과, 계측오류를 의심했던 3개 관측소가 SSE 상위 1~3위를 차지
 - 한계1: 4위 이하 관측소들과 SSE가 구분될 정도로 크지 않음
 - 한계2: 3개 관측소를 제외한 모델링에서도 RMSE가 개선되지 않음

#### 9.1.3 추가 분석방안 모색 및 가설2 수립
 - SSE 상위 3개 관측소의 데이터를 직접 불러와 육안으로 확인
 - 12시간 주기로 수위가 변동하는 주기성 확인  **(Fig9-3)**
 - 12시간 주기는 조석주기와 유사(조석영향을 증명한 것은 아님)
 - 가설: 조석에 의한 영향을 받는 관측소가 있을 것으로 추정

#### 9.1.4 가설2 검증(RMSE 감소 성공)

### 9.2 잔차모델링으로서의 분류기 학습(실패사례)

#### 9.2.1 실험배경 및 가설1 수립
 - 모델 선정 후 실제 수위상승량과 잔차의 산점도 분석
 - 실제 수위상승량이 증가할수록 잔차가 증가하는 패턴 확인  **(Fig9-4)**
 - 가설: 고잔차를 유발하는 독립변수의 공통 패턴을 식별할 수 있다면, 이를 활용하여 예측오차를 감소시킬 수 있을 것으로 판단

#### 9.2.2 가설 검증(고잔차를 유발하는 독립변수 패턴 탐색)
**종속변수 분위수별 SSE 기여도**
 - 상위 5% 종속변수에 SSE 약 70% 집중

**상위 5% 종속변수의 관측소별 데이터 개수**
 - 상위 9개는 Tidal그룹으로 분리
 - 나머지 50개 관측소에서 100~286개가 연속적으로 분포, 추가 경향성을 확인하기 어려움

**수위변동 하강국면에서 수위변동 임계치별 데이터 SSE 기여율**
 - 6시간 수위변동(<0) 임계치를 0 ~ -5범위로 설정하여 폭넓게 탐색
 - 전반적으로 수위하강치가 클수록 SSE 비율이 크고(예측력 저하), 0~-1.5에서 급증 확인  **(Fig9-4)**
 - 적용 보류: 수위변동을 기준으로 모델을 분리할 경우 동일 관측소와 강우사상에서도 수위변동에 따라 서로 다른 모델을 적용해야 하므로 현장 적용성이 낮다고 판단

**강우사상별 데이터 SSE 기여율**
 - 상위 6개 강우사상에 전체 SSE의 68% 이상이 집중
 - 모델링에 활용하려면 고잔차 강우사상의 공통 특성을 규명하고 독립 Validation에서도 식별할 수 있어야 함
 - 적용 보류: 분리 기준 도출에 필요한 분석 난이도와 범위가 본 실험의 범위와 목적을 넘어선다고 판단
 - 시사점: 고잔차 강우사상의 공통 특성을 규명하고 일반화가 가능한 분리기준을 마련하면 별도 모델링을 통한 예측 성능 개선 가능성

#### 9.2.3 잔차 분류모델 구축

**1. 실험 목적**
- 고잔차를 유발하는 독립변수의 공통패턴을 특정하지 못하는 상황
- 가설설정 방향 변경: 어떤 독립변수의 특성이 고잔차를 유발하는가? -> 고잔차 구간만 따로 식별하여 처리할 수 있는가?
- 독립변수만으로 회귀모델의 고잔차 주요원인인 과소예측 여부를 사전에 분류할 수 있는지 검증
- 과소예측 여부를 식별하는 신규 독립변수(`과소예측(down)` / `정상예측(normal)`)를 추가하여 회귀모델의 예측오차를 줄일 수 있는지 검증

**2. 잔차 분류기 학습 및 예측 과정**
- **① Train 재분할 -> 4-Fold는 분류기 학습용, 1-Fold는 분류기 검증용** 
  - Train 5-Fold 중 4-Fold를 학습용, 1-Fold를 분류 예측용으로 분리
  - Validation 데이터는 분류기 적용 후 최종 검증용으로만 사용
- **② 4-Fold 회귀모델링으로 OOF 잔차 생성**
  - 학습용 4-Fold만 교차검증으로 회귀모델 구현, 4-Fold의 OOF 예측값과 잔차 생성
- **③ 4-Fold 분류 라벨 정답 생성**
  - 생성된 잔차를 임계치를 기준으로 분류라벨(임계치 이상: `과소예측(down)` / 임계치 이하: `정상예측(normal)`) 부여  **(Fig9-5)**
  - 분류모델 정답 생성
- **④ 4-Fold 분류기 학습 -> 나머지 1-Fold 분류** 
  - 4-Fold 독립변수와 분류 라벨(예측대상)을 종속변수로 분류기 학습
  - 학습에서 제외된 1-Fold 분류예측(`과소예측(down)` / `정상예측(normal)`)
- **⑤ 전체 Train 예측** 
  - ①~④ 과정을 5회 반복, 각 1-Fold의 분류결과 병합으로 Train 전체에 대한 분류결과 완성
  - 분류결과를 Train의 독립변수로 추가
- **⑥ Validation 분류 예측**
  - 각 Fold를 분류한 분류모델(5개)로 Validation 분류, 다수결로 최종 라벨링(컬럼 추가)
- **중첩 GroupFold교차검증 적용사유 및 원리**
  - 회귀모델링: 학습용 4-Fold로만 잔차 생성 후, 나머지 1-Fold 분류라벨링, 5번 반복
  - 분류모델링: 학습용 4-Fold 학습, 나머지 1-Fold 예측 후 병합으로 5-Fold 분류라벨링
  - 최종 회귀모델링: 분류모델링 결과(Train)로 학습, Validation 데이터로 검증
  - 주안점: 각 Fold의 분류정답 생성 시, 해당 Fold가 제외된 회귀모델의 예측잔차를 활용, 학습정보 누출 방지

**3. 최종 산출물**
- Train 전체에 신규 독립변수 '과소예측여부(`과소예측(down)` / `정상예측(normal)`)' 생성
- Validation에도 동일한 라벨링 생성
- 기준 CatBoost 모델로 학습, 검증

#### 9.2.4 최종 결과
- 회귀모델 잔차의 임계치를 0.75(이상일때 `과소예측`)로 설정했을때만 RMSE 0.0005 개선
- 나머지 임계치에서는 RMSE 악화
- 적용보류: Train 5-Fold의 '종속변수-OOF잔차 산점도'에서 분류모델이 `과소예측(down)`으로 분류한 데이터만 표시해보니 실제 과소예측구간을 제대로 구분하지 못함  **(Fig9-5)**
- 결론: 일부 성능 개선, 과소예측 식별 능력 부족으로 신규 변수로서의 유효성을 확인하지 못함
