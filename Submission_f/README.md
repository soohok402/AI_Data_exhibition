# 하천수위변동 모델링
---
## 1. 프로젝트 개요

### 1.1 목적

- 기상·수문 데이터를 활용하여 '향후 6시간 동안의 최대 하천수위 상승량' 예측모델 개발
- 모델의 예측을 어렵게 하는 데이터 특성을 분석하고, 이에 대한 개선방안 고찰

### 1.2 모델링 방법론
- 이상치 분석 및 처리, RMSE 기반 독립변수 Ablation, 모델 비교 및 선정
- 모델 고도화: EDA와 초기 모델링을 통해 확인한 정보를 기반으로 관측소를 2개 그룹으로 분리하여 그룹별 모델링 시행

### 1.3 최종 모델
- **특이그룹(Tidal 그룹)**
  - 학습 방식: 단일 홀드아웃
  - 적용 모델: CatBoost, ExtraTrees 앙상블
- **일반그룹(Normal 그룹)**
  - 학습 방식: 5-Fold 교차검증
  - 적용 모델: CatBoost 5-Fold 예측 평균 앙상블

### 1.4 차별점
 - 물관리 분야에서 10년 이상 재직한 도메인 전문가들로 구성된 팀
 - 도메인 지식과 EDA를 기반으로 가설을 수립하고, 반복적인 실험과 검증을 통해 모델 개선
 - 단순히 Validation 성능을 높이는 것을 넘어, 예측잔차가 높은 구간을 탐색하고 해결방안을 모색하여 지속적으로 개선할 수 있는 모델링 방법론 제시

## 5. 모델 설명

### 5-1. 모델 개요
본 모델은 기상·수문·유역환경 데이터를 활용하여 향후 6시간동안 최대 하천수위 상승량을 예측하는 머신러닝 기반 회귀 모델입니다.
 - 탐색적 데이터 분석(EDA)과 모델링 과정에서 일부 관측소에서 수위 변동의 약 12시간의 주기성 발견
 - 학습데이터(Validation 데이터 제외)의 관측소별 전체 데이터 중 주기성 추정 데이터 비율이 10% 이상인 9개 관측소를 **Tidal그룹**, 나머지 관측소는 **Normal그룹**으로 분류
 - 각 그룹의 최적 모델 및 학습방식 탐색 후, 적용

### 5-2. 모델 특성
 - Tidal그룹은 단일 홀드아웃방식으로 CatBoost(45%), ExtraTrees(55%) 모델의 가중 앙상블로 예측
 - Normal 그룹은 5-Fold 교차검증으로 학습한 CatBoost 모델 5개의 예측값을 산술평균하여 예측
 - 최종적으로는 **두 그룹의 예측값을 결합하여** 전체 Test 데이터를 예측

### 5-3. 모델 사용 방법
본 프로젝트의 모든 Notebook은 Windows 11 환경의 VS Code 및 Jupyter Notebook을 기준으로 작성되었습니다.
**Notebook은 아래 순서에 따라 실행합니다.**

### 9.2 사후 잔차보정을 위한 분류모델(독립변수로 과소예측군을 예측) 학습(실패사례)

#### 9.2.1 실험배경 및 가설1 수립
 - 모델 선정 후 val데이터의 실제 수위상승량과 잔차의 산점도 분석에서
 - 실제 **수위상승량이 증가**할수록 과소예측으로 **잔차가 증가**하는 패턴 확인
 
   **[Fig 9-4. Fold별 예측값 및 잔차 산점도](figures/fig9-4_Fold별_예측값_및_잔차_산점도.png)**
 - 가설: 고잔차를 유발하는 독립변수의 공통 패턴을 식별할 수 있다면, 이를 활용하여 예측오차를 감소시킬 수 있을 것으로 판단

#### 9.2.2 가설 검증(고잔차를 유발하는 독립변수 패턴 탐색, train OOF 예측값 기준)

**종속변수 분위수별 SSE 기여도**
 - 상위 5% 종속변수에 SSE 약 70% 집중
 - 실제 수위상승량이 클수록 잔차가 급증하는 현상과 유사

**상위 5% 종속변수의 관측소별 데이터 개수**
 - 50개 이상의 관측소에서 100~830개가 연속적으로 분포, 명확한 경계를 확인할 수 없었음
 - 추후 상위 9개는 수위의 주기성이 확인되어 Tidal그룹으로 분리됨

**수위변동 하강 구간의 수위변동 임계치별 상대 MSE**
 - 6시간 수위변동 임계치를 0 ~ -5m로 변경하며 분석
 - 수위하강폭이 클수록 상대 MSE가 증가(예측력 저하)
 - 0~-1.5이하 구간에서 급격히 증가
 
   **[Fig 9-5. 6시간 수위 하강 임계치별 상대 MSE](figures/fig9-5_과거6h_수위변동값_임계치별_상대MSE.png)**
 - 적용 보류: 수위변동을 기준으로 모델을 분리할 경우 동일 관측소와 강우사상에서도 수위변동에 따라 서로 다른 모델을 적용해야 하므로 현장 적용성이 낮다고 판단

**강우사상별 데이터 SSE 기여율**
 - 상위 6개 강우사상에 전체 SSE의 68% 이상이 집중
 - 독립변수만으로 고잔차 강우사상을 식별할 수 있어야 별도 모델링이 가능함
 - 적용 보류: 고잔차 강우사상을 식별할 분리기준을 도출하는 분석의 난이도와 범위가 본 실험의 범위와 목적을 넘어선다고 판단
 - 시사점: 고잔차 강우사상의 공통 특성을 규명하고 일반화가 가능한 분리기준을 마련하면 별도 모델링을 통한 예측 성능 개선 가능성

#### 9.2.3 잔차 분류모델 구축

**1. 실험 목적**
- 고잔차를 유발하는 독립변수의 공통패턴을 특정하지 못하는 상황
- 가설설정 방향 변경: 독립변수의 어떤 특성이 고잔차를 유발하는가? -> 고잔차 구간만 따로 식별하여 분리할 수 있는가?
- 독립변수만으로 회귀모델의 과소예측 여부(고잔차 주요원인)를 사전에 분류할 수 있는지 검증
- 과소예측 여부를 식별하는 신규 독립변수(`과소예측(under_prediction) / 정상예측(normal_prediction)`)를 추가하면 회귀모델의 예측오차를 줄일 수 있는지 검증

**2. 분류정답 생성 및 학습, 검증 과정**
- **① train 재분할 -> 4-Fold는 분류기 학습용, 1-Fold는 분류기 검증용** 
  - train 5-Fold 중 4-Fold를 학습용, 1-Fold를 분류모델 검증용으로 분리
  - val 데이터는 각 Fold의 분류모델 생성 후 앙상블로 예측한 최종결과를 검증하는 용도로 원천 분리
- **② 4-Fold 회귀모델링으로 OOF 잔차 생성**
  - 학습용 4-Fold만으로 교차검증으로 회귀모델 구현, 4-Fold의 OOF 예측값과 잔차 생성
- **③ 4-Fold 분류 라벨 정답 생성**
  - 생성된 잔차를 임계치를 기준으로 분류라벨(임계치 이상: `과소예측(under_prediction)` / 임계치 미만: `정상예측(normal_prediction)` 부여(분류 정답 생성)
- **④ 4-Fold 분류기 학습 -> 나머지 1-Fold 분류** 
  - 4-Fold 독립변수와 분류 라벨(예측대상)을 종속변수로 분류기 학습
  - 학습에서 제외된 1-Fold 분류예측으로 (`과소예측` / `정상예측`)라벨링
  - 전제: 분류모델로 라벨링한 OOF 분류결과가 실제 과소예측군을 잘 식별할 수 있다.
- **⑤ 전체 train 예측** 
  - ①~④ 과정을 5회 반복, 각 1-Fold의 분류결과 병합으로 train 전체에 대한 분류결과 완성
  - 분류결과를 train의 독립변수로 추가
- **⑥ Validation 분류 예측**
  - 각 Fold를 분류한 분류모델(5개)로 val데이터 분류, 다수결로 최종 분류결과 컬럼 추가
  - 회귀모델의 val RMSE 비교로 효과 검증
- **중첩 GroupFold 교차검증 적용사유 및 원리**
  - 회귀모델링: 학습용 4-Fold로만 잔차 생성 후, 분류 정답 라벨 생성
  - 분류모델링: 학습용 4-Fold 정답으로 학습, 나머지 1-Fold 예측(5회) 후 5-Fold 병합
  - 최종 회귀모델링: train 전체의 분류예측 결과를 신규 독립변수로 학습, val 데이터로 검증
  - 주안점: train 분류정답 생성 시, 재분할하여 학습 Fold OOF 잔차만 활용, 검증 Fold는 분류기 학습에서 제외하여 정보 누출 방지

**3. 최종 산출물**
- train 전체에 신규 독립변수 '과소예측여부(`과소예측` / `정상예측`)' 생성
- val 데이터에도 동일한 라벨링 생성
- 기준 CatBoost 모델로 학습, 검증

#### 9.2.4 최종 결과
- 회귀모델 잔차의 임계치를 0.5, 0.75, 1.0, 1.25(이상일때 `과소예측(under_prediction)`)로 적용, 모든 조건에서 Validation RMSE 악화
- 적용보류: 분류모델 구축 이전에 생성한 Train 5-Fold 회귀 OOF 잔차 산점도에 분류모델의 OOF 예측결과를 중첩 표시하여 검토한 결과, 과소예측으로 분류된 데이터(빨간색)가 실제 과소예측 구간을 효과적으로 식별하지 못하는 것으로 나타남

    **[Fig 9-6. train OOF 잔차 임계치별 과소예측 분류 결과](figures/fig9-6_잔차임계치별_과소예측red_산점도.png)**

- 결론: 과소예측 식별 능력 부족으로 신규 변수로서의 유효성을 확인하지 못하여 신규 변수 채택 보류
- 시사점: 독립변수만으로 과소예측 여부를 신뢰성 있게 분류할 수 있다면, 관측소 및 강우사상별 예측오차 발생 가능성을 사전에 진단할 수 있고, 분류결과를 신규 독립변수로 활용하여 회귀모델의 예측오차를 줄이는 데 기여할 수 있음.
